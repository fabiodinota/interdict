## Cross-Phase Integration

### Issues Found (1)

**compilerModule missing auth guard** (Medium)
- `GET /api/v1/policies/:id/compilation-status` in `control-plane/src/modules/compiler/index.ts` has no `.use(authPlugin)` and no `{ auth: [...] }` option
- Any unauthenticated client can query compilation metadata
- **Fix:** Add `.use(authPlugin)` and `{ auth: ["read_only_auditor"] }` to match the pattern in `policiesModule`
- **Affected:** IDENT-03
