```typescript
export const departmentPolicyOverrides = pgTable(
  "department_policy_overrides",
  {
    id: uuid("id").primaryKey().defaultRandom(),
    departmentId: uuid("department_id").notNull()
      .references(() => departments.id, { onDelete: "cascade" }),
    policyId: uuid("policy_id").notNull()
      .references(() => policies.id, { onDelete: "cascade" }),
    enabled: boolean("enabled").notNull(),
    createdBy: uuid("created_by").references(() => users.id),
    createdAt: timestamp("created_at").defaultNow().notNull(),
    updatedAt: timestamp("updated_at").defaultNow().notNull(),
  },
  (table) => [
    uniqueIndex("dept_policy_override_unique").on(table.departmentId, table.policyId),
  ]
);
```

**schema/index.ts:** Add `export { departmentPolicyOverrides } from "./department-overrides";`

**model.ts:** TypeBox schemas for:
- GET /effective/:departmentId -- returns merged policy list
- PUT /override -- `{ department_id, policy_id, enabled }` to create/update override
- DELETE /override/:id -- remove override (revert to global default)
- PUT /mandatory/:policyId -- `{ is_mandatory: boolean }` (compliance_officer+ only)

**service.ts:** Create `DepartmentOverrideService`:

1. `getEffectivePolicies(departmentId, userId)` -- Server-side department membership check: verify userId belongs to departmentId via userDepartments table. If not, throw 403. Query all policies LEFT JOIN department_policy_overrides WHERE departmentId. Return merged list with fields: policyId, name, description, globalEnabled (policies.isActive), effectiveEnabled (override.enabled if exists, else globalEnabled), isMandatory, source ("Global" if no override, "Department override" if override exists), overrideId (null if no override).

2. `setOverride(departmentId, policyId, enabled, userId)` -- Verify department membership. Check if policy is mandatory -- if yes AND enabled=false, reject with 400 "Cannot disable mandatory policy". Upsert into department_policy_overrides (INSERT ON CONFLICT UPDATE).

3. `removeOverride(overrideId, userId)` -- Verify user owns the department of this override. Delete the override row (reverts to global).

4. `setMandatory(policyId, isMandatory)` -- Update policies.isMandatory. Only accessible to compliance_officer+ role. When setting mandatory=true, also delete any existing overrides that set enabled=false for this policy (force-enable everywhere).

**index.ts:** Elysia plugin at prefix `/api/v1/department-overrides`:
- `GET /effective/:departmentId` -- returns effective policy list. Auth: `department_manager` minimum. Department membership enforced server-side.
- `PUT /override` -- create/update override. Auth: `department_manager` minimum. Department membership enforced.
- `DELETE /override/:id` -- remove override. Auth: `department_manager` minimum.
- `PUT /mandatory/:policyId` -- toggle mandatory flag. Auth: `compliance_officer` minimum (higher than department_manager).

**Wire into control-plane/src/index.ts:** Import and `.use(departmentOverridesModule)`.

**use-department-policies.ts:** TanStack Query hooks:
- `useEffectivePolicies(departmentId)` -- GET /department-overrides/effective/:departmentId. Enabled only when departmentId is truthy.
- `useSetOverride()` -- useMutation PUT /department-overrides/override with `{ department_id, policy_id, enabled }`. On success, invalidate effective policies query.
- `useRemoveOverride()` -- useMutation DELETE /department-overrides/override/:id. On success, invalidate.
- `useSetMandatory()` -- useMutation PUT /department-overrides/mandatory/:policyId with `{ is_mandatory }`. For compliance_officer+ role only.

**MandatoryBadge.tsx:** Simple badge component:
- When `isMandatory=true`: shows Lock icon (lucide-react) with "Mandatory" text in a subtle gray badge
- Tooltip on hover: "This policy is mandatory and cannot be disabled by department managers"

**PolicyOverrideTable.tsx:** Table component (can use standard HTML table with Tailwind or TanStack Table):
- Columns: Policy Name, Description (truncated), Source (badge: "Global" blue, "Department override" purple), Status (toggle Switch), Mandatory (MandatoryBadge or empty)
- Status column: shadcn/ui Switch component. Disabled + locked appearance when isMandatory=true. When toggled, calls useSetOverride mutation. Optimistic update: toggle immediately, revert on error.
- Source column updates from "Global" to "Department override" when an override is created
- Row styling: subtle highlight on rows where source = "Department override" to visually distinguish customized policies
- If effectiveEnabled differs from globalEnabled, show a small "differs from global" indicator
