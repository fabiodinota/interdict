Create reusable Helm template snippets for sidecar injection:

1. **_sidecar-container.tpl** -- Named template `interdict.sidecar.container` that outputs a native sidecar container spec (KEP-753 pattern):
   ```yaml
   - name: interdict-kernel
     image: "{{ .Values.kernel.image.repository }}:{{ .Values.kernel.image.tag | default .Chart.AppVersion }}"
     restartPolicy: Always  # KEP-753 native sidecar
     ports:
       - containerPort: 8443
         name: proxy
     env:
       # All KERNEL_* env vars from values
       - name: KERNEL_LISTEN_ADDR
         value: "{{ .Values.kernel.listenAddr }}"
       # ... all kernel env vars
     volumeMounts:
       - name: interdict-certs
         mountPath: /certs
         readOnly: true
       - name: interdict-ca-certs
         mountPath: /data/certs
     resources: {{ toYaml .Values.sidecar.resources | nindent 6 }}
     securityContext:
       runAsNonRoot: true
       runAsUser: 1000
       allowPrivilegeEscalation: false
   ```
   This goes in `initContainers` of the target pod (native sidecar pattern).

2. **_sidecar-init.tpl** -- Named template `interdict.sidecar.iptablesInit` for transparent traffic redirect:
   ```yaml
   - name: interdict-iptables
     image: "{{ .Values.kernel.image.repository }}:{{ .Values.kernel.image.tag | default .Chart.AppVersion }}"
     command: ["/bin/sh", "-c"]
     args:
       - |
         # Redirect outbound traffic to AI vendors through kernel proxy
         {{- range .Values.sidecar.trafficRedirect.targetHosts }}
         iptables -t nat -A OUTPUT -p tcp -d {{ . }} --dport 443 -j REDIRECT --to-port 8443
         {{- end }}
         {{- if not .Values.sidecar.trafficRedirect.targetHosts }}
         # Default: redirect based on kernel allowlist vendors
         {{- range .Values.kernel.allowlistVendors }}
         iptables -t nat -A OUTPUT -p tcp -d {{ . }} --dport 443 -j REDIRECT --to-port 8443
         {{- end }}
         {{- end }}
     securityContext:
       capabilities:
         add: ["NET_ADMIN"]
       runAsUser: 0
     restartPolicy: Never  # Not a sidecar, just init
   ```
   This template is ONLY included when `.Values.sidecar.trafficRedirect.enabled` is true.
   When false, the example shows HTTP_PROXY/HTTPS_PROXY env vars on the app container instead.

3. **example-app.yaml** -- Conditional on `.Values.sidecar.exampleApp.enabled` (default: false). Creates a sample Deployment showing how to use the sidecar:
   - Main container: nginx:alpine (placeholder AI app)
   - initContainers: includes `interdict.sidecar.iptablesInit` (if trafficRedirect enabled) and `interdict.sidecar.container`
   - Volumes: interdict-certs (from Secret or PVC), interdict-ca-certs
   - If trafficRedirect disabled, add HTTP_PROXY=http://localhost:8443 and HTTPS_PROXY=http://localhost:8443 to main container env
   - Comments explaining: "Copy the initContainers and volumes sections into your own Deployment to add Interdict sidecar"
   - Include both modes as comments so operators can see both options

Also update `helm/interdict/values.yaml` to add the sidecar section if not already present (from Plan 01 it should have stubs). Ensure these values exist:
```yaml
sidecar:
  enabled: false
  resources:
    requests:
      memory: "128Mi"
      cpu: "100m"
    limits:
      memory: "512Mi"
      cpu: "500m"
  trafficRedirect:
    enabled: true
    targetHosts: []  # Empty = use kernel.allowlistVendors
  exampleApp:
    enabled: false
```

And `kernel.allowlistVendors` should be a list (not JSON string) for template iteration:
```yaml
kernel:
  allowlistVendors:
    - "api.openai.com"
    - "api.anthropic.com"
```
