  <name>Task 1: macOS/Linux CA trust installer script</name>
  <files>scripts/install-ca-trust.sh</files>
  <action>
Create `scripts/install-ca-trust.sh` -- a portable shell script that installs the Interdict CA certificate into the system trust store on macOS and Linux.

Requirements:
- Shebang: `#!/bin/bash` with `set -euo pipefail`
- Usage: `sudo ./install-ca-trust.sh /path/to/interdict-ca.pem`
- Accept cert path as first positional argument (required)
- Support optional `--remove` flag to uninstall the CA cert

**Validation checks (run before any modification):**
1. Cert file argument provided and file exists
2. Running as root (id -u == 0), exit with clear error if not
3. Cert file is valid PEM (openssl x509 -in $CERT_PATH -noout succeeds)

**macOS (Darwin):**
- Install: `security add-trusted-cert -d -r trustRoot -k "/Library/Keychains/System.keychain" "$CERT_PATH"`
- Remove: `security remove-trusted-cert -d "$CERT_PATH"`
- Verify: `security find-certificate -c "interdict" "/Library/Keychains/System.keychain"` succeeds

**Linux (Debian/Ubuntu -- has update-ca-certificates):**
- Install: Copy cert to `/usr/local/share/ca-certificates/interdict-ca.crt`, run `update-ca-certificates`
- Remove: Delete the file, run `update-ca-certificates --fresh`
- Verify: `openssl verify -CApath /etc/ssl/certs/ /usr/local/share/ca-certificates/interdict-ca.crt`

**Linux (RHEL/CentOS/Fedora -- has update-ca-trust):**
- Install: Copy cert to `/etc/pki/ca-trust/source/anchors/interdict-ca.pem`, run `update-ca-trust extract`
- Remove: Delete the file, run `update-ca-trust extract`
- Verify: `trust list | grep -i interdict`

**Output:**
- Print SUCCESS with green color (using ANSI escape codes) on completion
- Print ERROR with red color on failure
- Print the subject/issuer of the installed cert for confirmation
- If --remove flag used, confirm removal

**Header comment:** Include usage examples, supported platforms, and a note that this script installs the Interdict MITM proxy CA -- NOT the internal mTLS CA (those are separate).

Make the script executable (note in action -- executor should chmod +x).

<task type="auto">
  <name>Task 2: Windows CA trust installer script (PowerShell)</name>
  <files>scripts/install-ca-trust.ps1</files>
  <action>
Create `scripts/install-ca-trust.ps1` -- a PowerShell script that installs the Interdict CA certificate into the Windows trust store.

Requirements:
- `#Requires -RunAsAdministrator` directive at top
- Parameters: `-CertPath` (mandatory string), `-Remove` (switch)

**Validation checks:**
1. Cert file exists at CertPath (Test-Path)
2. Script is running as Administrator (the #Requires directive handles this)

**Install mode (default):**
- Import-Certificate -FilePath $CertPath -CertStoreLocation Cert:\LocalMachine\Root
- Display the installed certificate thumbprint and subject for confirmation
- Write-Host with -ForegroundColor Green on success

**Remove mode (-Remove flag):**
- Find the certificate by subject (CN=interdict) in Cert:\LocalMachine\Root
- Remove-Item on the cert store path
- Confirm removal

**Error handling:**
- try/catch around Import-Certificate
- Write-Error with clear message on failure
- Exit code 1 on failure

**Header comment block:**
```powershell
<#
.SYNOPSIS
    Install or remove the Interdict proxy CA certificate from Windows trust store.
.DESCRIPTION
    This script installs the Interdict MITM proxy CA certificate into the
    Windows Trusted Root Certification Authorities store. This allows browsers
    and applications to trust the Interdict proxy for AI traffic inspection.
.PARAMETER CertPath
    Path to the Interdict CA certificate file (PEM or CER format).
.PARAMETER Remove
    Remove the Interdict CA certificate instead of installing it.
.EXAMPLE
    .\install-ca-trust.ps1 -CertPath .\interdict-ca.pem
.EXAMPLE
    .\install-ca-trust.ps1 -CertPath .\interdict-ca.pem -Remove
#>
```
