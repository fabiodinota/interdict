Create the Helm chart scaffold:

1. **Chart.yaml** -- apiVersion: v2, name: interdict, appVersion: "1.1.0", version: 0.1.0. Dependencies:
   - bitnami/postgresql ~16.0 (condition: postgresql.enabled)
   - bitnami/clickhouse ~6.0 (condition: clickhouse.enabled)
   - bitnami/minio ~14.0 (condition: minio.enabled)
   All from oci://registry-1.docker.io/bitnamicharts.

2. **values.yaml** -- Complete values file mapping ALL env vars from env.example. Structure:
   - `global.imageRegistry`, `global.imagePullSecrets`
   - `kernel.*` (image, replicaCount, listenAddr, orgId, logLevel, logFormat, allowlistVendors, mtls.enabled, resources with requests/limits, service.type/port, all KERNEL_* env vars from env.example)
   - `controlPlane.*` (image, replicaCount, port, grpcPort, resources, service)
   - `evidenceCollector.*` (image, replicaCount, grpcPort, signingMode, all COLLECTOR_* env vars, resources, service)
   - `dashboard.*` (image, replicaCount, port, ingress with enabled/className/hosts/tls, resources, service)
   - `certInit.enabled` (true), `certInit.image` (alpine:latest)
   - `postgresql.*` (enabled: true, auth.username/password/database/existingSecret)
   - `clickhouse.*` (enabled: true)
   - `minio.*` (enabled: true, auth.rootUser/rootPassword/existingSecret)
   - Use `existingSecret` pattern for all passwords (never real passwords in values.yaml)
   - Default image registry: ghcr.io/interdict/ per research recommendation
   - Every container MUST have resource requests and limits

3. **.helmignore** -- Standard Helm ignore file (charts/, .git, *.swp, etc.)

4. **_helpers.tpl** -- Standard helpers:
   - `interdict.name` (chart name)
   - `interdict.fullname` (release-name-chart-name, truncated to 63 chars)
   - `interdict.chart` (chart-version)
   - `interdict.labels` (standard K8s labels: app.kubernetes.io/name, instance, version, managed-by)
   - `interdict.selectorLabels` (name + instance only)
   - `interdict.serviceAccountName`

5. **NOTES.txt** -- Post-install instructions showing URLs, how to get dashboard URL, CA cert export command.

6. **cert-init-job.yaml** -- Kubernetes Job with Helm hooks:
   - annotations: helm.sh/hook: pre-install,pre-upgrade; helm.sh/hook-weight: "-5"; helm.sh/hook-delete-policy: hook-succeeded,before-hook-creation
   - Runs the existing generate-internal-ca.sh script from ConfigMap
   - Mounts cert-script ConfigMap and a PVC for /certs output
   - Output certs are stored in a PVC (not a Secret, since the Job generates them)
   - Conditional on `.Values.certInit.enabled`
   - Uses alpine image with openssl installed

7. **configmap-cert-script.yaml** -- Embed the generate-internal-ca.sh content directly (copy from docker/certs/generate-internal-ca.sh). Conditional on certInit.enabled.

8. **secret-tls.yaml** -- Template for operator-provided TLS certs when certInit.enabled=false. Uses existingSecret pattern.

9. **minio-init-job.yaml** -- Post-install hook Job that creates the evidence bucket. Mirrors the minio-init service from docker-compose. Runs `mc alias set` + `mc mb --ignore-existing`. Conditional on minio.enabled. Hook-weight: "5" (runs after minio is ready).

Security contexts on all pods per research Pattern 4:
- runAsNonRoot: true, runAsUser: 1000, runAsGroup: 1000, allowPrivilegeEscalation: false
- Exception: cert-init Job may need root for key generation (keep as-is from Alpine default)

Create Kubernetes Deployment + Service + ConfigMap templates for each Interdict service, translating directly from docker-compose.yml:

**Control Plane (control-plane/):**
- Deployment with 1 replica (configurable), image from values, port 3000 + gRPC 50052
- Environment from ConfigMap: DATABASE_URL, CLICKHOUSE_URL, CLICKHOUSE_DATABASE, PORT, WASM_STORAGE_DIR, OPA_BINARY_PATH, INTERDICT_GRPC_PORT, MTLS_ENABLED, MTLS_CA_CERT_PATH, MTLS_CERT_PATH, MTLS_KEY_PATH
- Volume mount: certs PVC at /certs (readOnly: true)
- Init container: wait for postgres readiness (wget loop on postgres service)
- Readiness probe: HTTP GET /health on port 3000
- Liveness probe: HTTP GET /health on port 3000 (higher failure threshold)
- Service: ClusterIP exposing ports 3000 (HTTP) and 50052 (gRPC)
- ConfigMap: all non-secret env vars from values
- Security context: runAsNonRoot: true, runAsUser: 1000, readOnlyRootFilesystem: false (needs /app/data/wasm writable), allowPrivilegeEscalation: false

**Evidence Collector (evidence-collector/):**
- Deployment: image from values, gRPC port 50051
- Environment: all COLLECTOR_* vars, CLICKHOUSE_*, AWS_*, MTLS_*, RUST_LOG from values
- Volume mounts: certs PVC at /certs (readOnly), signing-keys PVC at /data/keys
- Init container: wait for clickhouse readiness
- Service: ClusterIP exposing port 50051
- Security context: runAsNonRoot: true, runAsUser: 1000, allowPrivilegeEscalation: false

**Kernel (kernel/):**
- Deployment: image from values, port 8443
- Environment: all KERNEL_* vars from values via ConfigMap
- Volume mounts: certs PVC at /certs (readOnly), ca-certs PVC at /data/certs
- Init container: wait for control-plane readiness (wget on /health)
- Service: ClusterIP exposing port 8443
- ConfigMap: all KERNEL_* non-secret env vars
- Security context: runAsNonRoot: true, runAsUser: 1000, allowPrivilegeEscalation: false

**Dashboard (dashboard/):**
- Deployment: image from values, port 3001
- Environment: CONTROL_PLANE_URL pointing to control-plane service, NODE_ENV: production
- Init container: wait for control-plane readiness
- Service: ClusterIP exposing port 3001 (note: docker-compose maps 8080:3001, but in K8s the Ingress handles external access)
- Ingress: conditional on dashboard.ingress.enabled, supports className, hosts array, TLS array. Annotate for cert-manager if tls configured.
- Security context: runAsNonRoot: true, runAsUser: 1000, readOnlyRootFilesystem: false (Next.js needs /app/.next writable), allowPrivilegeEscalation: false

**All templates must:**
- Use `{{ include "interdict.fullname" . }}` for resource names
- Use `{{ include "interdict.labels" . }}` for metadata.labels
- Use `{{ include "interdict.selectorLabels" . }}` for spec.selector

- Reference `.Values.{service}.resources` for resource requests/limits
- Use `imagePullPolicy: {{ .Values.{service}.image.pullPolicy }}`
- Include `imagePullSecrets` from global.imagePullSecrets if set
