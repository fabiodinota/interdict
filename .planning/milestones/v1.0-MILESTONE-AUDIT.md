## Integration Findings

### EVID-STUB-01 (Severity: Medium — Known, Deferred)

`actor_identity`, `department`, `model`, `response_hash`, and `token_count` are hard-coded stubs in `build_evidence_event()` (`connect.rs` lines 608-614). All evidence records in ClickHouse carry placeholder values. Audit trail filtering by actor/model will return zero results until Phase 7 wires identity. Documented dependency on Phase 7, not a v1.0 gap.

### DELTA-ENTRYPOINT-01 (Severity: Low — Latent)

`apply_delta()` in `snapshot.rs` reconstructs proto entries with `entrypoint: String::new()` for existing policies. The entrypoint is not consumed by `build_regorus_pool()` so there is no active runtime bug, but future changes could regress. Flagged for cleanup.

### AUTH-MISSING (Severity: High for Production — Expected for v1.0)

All Phase 5 HTTP endpoints and Phase 6 gRPC port are unauthenticated. Phase 7 (Identity, Access & Security) is explicitly out of v1.0 scope. Deployments must enforce network-level isolation until Phase 7 ships.
