  <action>
    1. Add dependencies to `control-plane/package.json`:
       ```
       "@grpc/grpc-js": "^1.12.0",
       "@grpc/proto-loader": "^0.7.0"
       ```
       Run `cd control-plane && bun install` after.

    2. Update `control-plane/src/config.ts`:
       - Add `grpcPort: number` field (default 50052, from env `INTERDICT_GRPC_PORT`)
       - Add `grpcMaxMessageSize: number` field (default 16 * 1024 * 1024 = 16MB, per research recommendation)

    3. Create `control-plane/src/modules/distribution/tracker.ts`:
       - `KernelConnection` interface:
         - `kernelId: string`
         - `orgId: string`
         - `deptId: string`
         - `teamId: string`
         - `currentVersion: number` (last ACKed version)
         - `stream: grpc.ServerWritableStream<any, any>` (the open server-stream)
         - `connectedAt: Date`
         - `lastAckAt: Date | null`
       - `KernelTracker` class:
         - `private connections: Map<string, KernelConnection>`
         - `register(kernelId: string, orgId: string, deptId: string, teamId: string, stream: grpc.ServerWritableStream)` — stores the connection, logs connection event
         - `unregister(kernelId: string)` — removes from map, logs disconnection
         - `acknowledge(kernelId: string, version: number, accepted: boolean, errorMessage: string)` — updates currentVersion on ACK, logs NACK with error
         - `getConnected(): KernelConnection[]` — returns all active connections
         - `getConnection(kernelId: string): KernelConnection | undefined`
         - `connectedCount(): number`
       - Export singleton: `export const kernelTracker = new KernelTracker();`
       - `broadcastUpdate(update: PolicyUpdateMessage): void`:
         - Iterate all connected kernels
         - For each, try `stream.write(update)`
         - On write error, unregister the kernel (connection dropped)
         - Log broadcast count: "Policy update v{version} broadcast to {N} kernels"

    4. Create `control-plane/src/modules/distribution/server.ts`:
       - Load the proto definition using `@grpc/proto-loader` with the proto file at `../../proto/interdict/policy/v1/policy_distribution.proto`
         - protoLoader options: keepCase=true, longs=Number, defaults=true, oneofs=true
       - Create gRPC package definition and get the PolicyDistribution service

       - `buildFullSnapshot(db: any, orgId: string, deptId: string, teamId: string): Promise<PolicyUpdateMessage>`:
         - Query all active policies with their current versions that have compilationStatus="compiled"
         - For policies with wasmPath, read the wasm file from disk to get wasm_bytes
         - Build PolicyEntry for each policy with:
           - policy_id, name, version from DB
           - wasm_bytes from filesystem (Buffer.from(await Bun.file(wasmPath).arrayBuffer()))
           - wasm_hash from DB
           - rego_source, entrypoint from the version row
           - scope: **v1 known limitation** — all policies are sent with org-level scope (dept_id="" and team_id="" means org-wide). The Phase 5 DB schema does not include a policy-scope join table for per-department/team policy assignment. The kernel's HierarchyResolver will receive org-scoped entries only. Per-department/team scope population from the database is **deferred to Phase 7** (requires a `policy_scope_assignments` join table or equivalent). Document this limitation in STATE.md after implementation.
           - fail_mode: default FAIL_CLOSED
         - Return PolicyUpdate with type=FULL_SNAPSHOT, version=global monotonic counter
         - The global version counter: query `SELECT MAX(version) FROM policy_versions WHERE compilation_status='compiled'` (via Drizzle: `db.select({ maxVersion: max(policyVersions.version) }).from(policyVersions).where(eq(policyVersions.compilationStatus, 'compiled'))`) and cast the result to a `u64`/`number`. This uses the existing `policyVersions.version` column as the monotonic counter, paired with content hashes per CONTEXT.md decision ("monotonic version counter paired with content hash"). If no compiled versions exist, use version=0. Do NOT use `Date.now()` — it is not a true structured counter and can collide on rapid compilations.

       - `Subscribe` handler (server-streaming):
         - Extract kernel_id, current_version, org_id, dept_id, team_id from request
         - Register kernel in tracker with the stream
         - Build and send full snapshot (even if current_version > 0, for simplicity in v1 — delta optimization can come later)
         - Set up disconnect handlers: `call.on("cancelled", ...)` and `call.on("error", ...)` to unregister
         - Do NOT call `call.end()` — keep the stream open for future pushes

       - `Acknowledge` handler (unary):
         - Extract kernel_id, version, accepted, error_message
         - Call tracker.acknowledge(...)
         - Return { acknowledged: true }

       - `startDistributionServer(db: any, grpcPort: number, maxMessageSize: number): grpc.Server`:
         - Create grpc.Server with maxReceiveMessageLength and maxSendMessageLength
         - Add PolicyDistribution service with Subscribe and Acknowledge handlers
         - Bind to `0.0.0.0:${grpcPort}` with insecure credentials (mTLS in Phase 7)
         - Return the server instance

       - `stopDistributionServer(server: grpc.Server): Promise<void>`:
         - Call server.tryShutdown() wrapped in a promise

    5. Create `control-plane/src/modules/distribution/index.ts`:
       - Export `startDistributionServer`, `stopDistributionServer` from server.ts
       - Export `kernelTracker`, `broadcastUpdate` from tracker.ts

           ```
           {
             version: job.version, // use the policy version number as the monotonic counter (same source as buildFullSnapshot)
             type: 1, // DELTA
             policies: [{
               policy_id: job.policyId,
               name: policy_name, // query from policies table
               version: job.version,
               wasm_bytes: Buffer.from(wasmBytes),
               wasm_hash: result.wasmHash,
               rego_source: job.regoSource,
               entrypoint: job.entrypoint,
               scope: { org_id: "", dept_id: "", team_id: "", vendor_ids: [] }, // org-level default
               fail_mode: 0, // FAIL_CLOSED default
             }],
             removed_policy_ids: [],
           }
           ```
